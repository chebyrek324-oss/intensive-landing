# intensive-landing

Лендинг "Интенсив по заработку на ИИ в 2026" (Матвей Мешков). Next.js 14 App Router → static export → Cloudflare Pages.

## Деплой
- Платформа: **Cloudflare Pages**
- Framework preset: **Next.js (Static HTML Export)**
- Build command: `npm run build`
- Build output directory: `out`
- Node version: `20` (или 22)

## Локально
```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # генерит папку out/
```
